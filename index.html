    几何工坊 · 使用说明

    三步上手、表达式速查、交互手势与默认约束，一页看完

    一、三步上手

    1. 在左侧面板输入表达式或创建图形，回车即绘制
    2. 画布上滚轮缩放、拖拽平移、点击选中对象、拖动顶点或控制点调整形状
    3. 右侧面板查看实时读数，拖动参数滑块看图形联动，选中对象后点计算按钮

    二、表达式速查

    三角函数sin cos tan cot sec csc；反三角 arcsin arccos arctan arccot（也可写 asin 等）；双曲 sinh cosh tanh
    对数ln、lg、log(x, b)；带底数可写 log₂(x) 或 log_2(x)
    根号√2、√(x+1)、∛8（也可写 sqrt / cbrt）
    绝对值|x|、|x| + |y|（成对出现；复杂嵌套请用 abs()）
    取整（高斯函数）[x]、⌊x⌋、⌈x⌉（不超取整 / 上取整）；也可写 floor / ceil / gauss / int
    阶乘5!、x!（整数精确；非整数自动用 Γ 函数平滑）
    度数sin(30°)、45°（自动换算弧度）
    上标直接打x²、x³、x⁻¹（等价于 x^2、x^3、x^-1）
    常数pi / π、e（自然常数）、∞
    其它函数abs、min、max、sign、exp、round、atan2
    不等式y > x^2、x^2 + y^2 ≤ 4（画区域）；x^2 - a > 0（求一元解集）；支持 < > ≤ ≥ ≠ 与 <= >= !=
    参数a b c d f g h k 共 8 个，出现即生成滑块（e 已保留给自然常数）
    省略乘号2x、3sin(x)、πr、2√3、2|x| 都会自动补上乘号
    输入示例y = sin(x)；|x| + |y| = 1；x^2/4 + y^2/9 = 1；r = 2*cos(θ)；x = cos(t), y = sin(t)
    立体曲面立体模式下含 x 与 y 的表达式如 z = sin(x)*cos(y) 自动切为曲面

    三、图形与交互

    平面模式滚轮缩放（以指针为中心）、空白处拖拽平移、点击选中、拖顶点移动
    空间图形立体模式的「几何体」面板顶部可一键创建空间点 / 线段 / 直线 / 平面，拖动顶点即可调整；也可以先建点、选中两点连线、三点定平面
    立体模式拖拽旋转、滚轮缩放、Shift 或右键拖拽平移、双击复位视角；点选对象后拖动 = 在水平面内移动；按住 Ctrl 拖动 = 竖直升降（调高度）；函数与曲面同样能移动：先点选，再拖动平移，右侧面板还可设位置与旋转角度（∠x / ∠y / ∠z）；坐标也可在右侧直接输入
    触摸屏单指平移或旋转，双指捏合缩放，双指拖动平移
    符号输入输入框下方有符号条：√ ² | | ! [ ] ≤ ≥ ° 等一键插入，手机上也顺手
    命名的点直接写 P(1, 2) 即可命名为 P；对象列表里点铅笔图标（或双击名字）可随时改名，关联图形名自动跟随（△ABC 改 A 为 P → △PBC）
    撤销 / 重做Ctrl+Z 撤销、Ctrl+Shift+Z（或 Ctrl+Y）重做，也可以点工具栏按钮；添加、删除、清空、拖动、改参数都能撤
    自动保存场景自动保存在本机浏览器里，关掉页面再打开会自动恢复；数据不上传任何地方
    选择与多选依次点选对象即可多选（最多 3 个，无需按任何键），再点一次取消、点空白处清空；连选两个平面求二面角、选中两点连线、三点定平面（立体模式）
    导数与圆锥曲线选中函数曲线可求导 f′(x)（可一键把导函数画到画布）、分析极值与单调性（可标注极值点）、作切线（指定 x 或选中曲线上的点）；隐式方程可做圆锥曲线分析，自动识别椭圆 / 双曲线 / 抛物线并给出中心、半轴、焦点、离心率、准线、渐近线等；直线与曲线选中后可求弦长

    四、默认约束（明确设定）

    参数数量8 个（a b c d f g h k）；滑块默认范围 [-5, 5]，步长 0.05，可手动输入精确值并自动扩展范围
    数值精度默认 3 位小数，可切 2 / 4 / 6 位；内部计算使用双精度
    可绘制范围平面视图半宽 0.2 至 500 之间自由缩放，超出会被限制
    采样密度显式函数逐像素采样；隐式方程为自适应网格（约每 6px 一格，上限 260×260，拖动时自动降密）；极坐标 1800 点；参数方程 2400 点
    曲线参数范围极坐标 θ ∈ [0, 2π]；参数方程 t ∈ [-2π, 2π]
    曲面网格48×48（拖动中 32×32），仅立体模式支持
    交点范围显式×显式、显式×隐式、直线×任意曲线；隐式×隐式暂不支持
    对象上限曲线 12 条、点 60 个、图形 40 个、几何体 8 个（软上限，超出会提示）

    进阶玩法：浏览器控制台里可以通过 window.__Geo 直接调用内部引擎，做批量实验或二次开发
