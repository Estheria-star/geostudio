# 几何工坊 GeoStudio

🧮 **在线使用 → https://geo.startian.top/**

> 面向高中数学教学的平面几何 × 立体几何可视化工作台：单文件、零依赖、离线可用

## 功能一览

**平面几何**

- 函数与方程同绘：显式 `y=f(x)`、隐式 `F(x,y)=0`、极坐标 `r=f(θ)`、参数方程 `x=x(t), y=y(t)`
- 隐式乘法：`2x`、`3sin(x)`、`πr` 可直接输入
- 画布缩放平移、拖拽顶点、点击选中
- 实时读数：斜率、倾斜角、交点坐标
- 向量关系自动判定：垂直 / 平行 / 相交 / 重合 / 异面
- 基础图形全家桶（特殊三角形、平行四边形、圆、椭圆等）+ 一键求面积（附推导步骤）

**立体几何**

- 空间坐标系、9 种几何体、拖拽旋转、滚轮缩放
- 平面功能完整继承（z=0 平面绘制）；含 x、y 的表达式自动升级为 `z=f(x,y)` 曲面
- 一键求体积 / 表面积
- 线线 / 线面 / 面面距离、二面角（含图解与公式步骤）

**通用**

- 8 个参数（a b c d f g h k）滑块实时联动，含参点自动跟随
- 13 个教材预设场景、PNG 导出、精度 2/4/6 位可调
- 暗色 / 亮色主题，适配课堂投影与手机

## 使用

直接打开上方链接；或下载 `index.html` 后双击本地使用（除字体外无任何外部依赖，断网可用）

## 技术

纯 HTML + CSS + JavaScript 单文件（约 250 KB / 5200 行），自研表达式解析器与 Canvas 2D/3D 渲染引擎，零运行时依赖
